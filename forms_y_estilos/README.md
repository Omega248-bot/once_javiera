# Etiquetas importantes

### label
Describe cada campo del formulario.
Está conectado con el input mediante el atributo "for".

### input
Permite ingresar datos.
Tipos usados en el formulario:

-  text: para nombre y asunto
- email: para correo electrónico
- number: para edad
- tel: para teléfono
- radio: para elegir una sola opción
-checkbox: para seleccionar opciones múltiples

### textarea
- Permite escribir mensajes largos.

### select
- Muestra un menú desplegable con opciones.

### Button
- Botones del formulario:

### submit: 
- envía los datos
### reset: 
- borra todo el formulario
CSS (diseño)

### El CSS se encarga de la apariencia del formulario:

Usa variables para colores 
Centra el formulario en la pantalla
Aplica bordes redondeados y sombras
Organiza los campos con flexbox y grid
Cambia el estilo al interactuar (focus, hover)
Valida visualmente los campos (rojo = error, verde = correcto)
Se adapta a dispositivos móviles (responsive)
