# Requerimientos de Software

- Son las necesidades y condiciones que debe cumplir un sistema.
- Deben ser claros, verificables y documentados.

# Requerimientos Funcionales (RF)

- Describen qué hace el sistema.
- Ejemplos:
  - Iniciar sesión.
  - Registrar usuarios.
  - Generar reportes.

# Requerimientos No Funcionales (RNF)

- Describen cómo funciona el sistema.
- Incluyen:
  - Seguridad.
  - Rendimiento.
  - Usabilidad.
  - Confiabilidad.

# Atributos de Calidad

- Adecuación funcional.
- Eficiencia.
- Seguridad.
- Usabilidad.
- Mantenibilidad.
- Portabilidad.

# Historias de Usuario

- Expresan necesidades de los usuarios.
- Estructura:
  - Como [usuario].
  - Quiero [funcionalidad].
  - Para [beneficio].

# Conclusión

- Los RF indican qué hace el sistema.
- Los RNF indican cómo debe hacerlo.
- Ambos son esenciales para desarrollar software de calidad.
